# IPL Data Analytics (Power BI )

## Overview

This project analyzes IPL data from 2008 to 2025 using Power BI . The goal is to explore team performance, player achievements, and match statistics to generate meaningful insights for cricket analytics.

---

## Problem Statement

How can we analyze IPL data to identify top-performing teams, player trends, and key match insights to support data-driven sports analysis?

---

## Dataset Details

* Covers IPL seasons from 2008 to 2025
* Includes multiple datasets:

  * Match-level data
  * Ball-by-ball data
  * Player data
  * Team data

### Key Attributes:

* Runs
* Wickets
* Fours & Sixes
* Matches Played
* Team Names
* Venues
* Player Performance

---

## Data Cleaning & Transformation

Performed using Power Query :

* Removed duplicate records
* Handled missing/null values
* Standardized team and player names
* Corrected data types
* Created calculated columns for analysis
* Optimized dataset for performance

---

## Dashboard Features

### 🔍 Interactive Filters

* IPL Season filter
* Dynamic visual updates

### 📊 Visualizations

* KPI Cards → Overall statistics
* Points Table → Team rankings
* Orange Cap → Top run scorer
* Purple Cap → Top wicket taker
* Tables → Detailed breakdown

---

## Key Insights

* Certain teams consistently dominate across seasons
* High run scorers significantly impact match outcomes
* Increase in six-hitting trends in recent seasons
* Strong correlation between top players and team success
* Mid-table teams show high performance variability
